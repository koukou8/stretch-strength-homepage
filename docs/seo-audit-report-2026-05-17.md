- `HealthClub` に `paymentAccepted`、`currenciesAccepted`、`areaServed`、`@id`、`hasMap` を追加

- `index.html` の `BreadcrumbList` を削除（トップページに不要）
- トレーナー資格（NSCA-CPT等保有していれば）を `Person.hasCredential` に追加

**追加例（HealthClub に areaServed）:**

- GBPへの直接リンク + 「Googleで口コミを書く」ボタンを設置

- `.htaccess` 作成 → HSTS、X-Frame-Options、X-Content-Type-Options、Referrer-Policy を設定

## 戦略的ポジショニング（SXOからの示唆）

「奥沢 パーソナルジム」「自由が丘 パーソナルトレーニング」の SERP 1ページ目は**比較・まとめサイトが支配**しており、単一ジムの公式サイトが有機検索で勝つのは事実上困難。リソースは以下に集中すべき：

1. **ローカルパック獲得（GBP最適化）** ← 最大ROI
2. **比較サイト掲載の維持・拡大**（MELOS等への掲載先として公式サイトを整備）
3. **比較サイトが薄いロングテール**（「奥沢 ストレッチ 姿勢改善」「パーソナルジム ストレッチ特化 自由が丘」）でブログ専門性勝負

## キーワード戦略分析（2026-05-17 追記）

### ターゲットキーワードと現状の順位

| キーワード | 現状 |
|---|---|
| 奥沢 ストレッチ | 上位表示 ✓ |
| 自由が丘 ストレッチ | 上位表示 ✓ |
| 奥沢 パーソナルジム | 上位表示できていない |
| 自由が丘 パーソナルジム | 上位表示できていない |
| 奥沢 マッサージ | 上位表示できていない |
| 自由が丘 マッサージ | 上位表示できていない |

### なぜ「ストレッチ」だけ上位表示できているか

3条件が噛み合っているため：

1. **競合密度が比較的低い** — ストレッチ専門店のSERPはマッサージ・パーソナルジムほど飽和していない
2. **タイトルとの一致度が高い** — `<title>` に「ストレッチ」が明示されている
3. **差別化が刺さる** — 「ストレッチ専門店で1,000セッション以上」という権威性がストレッチ検索意図と直結

逆に言うと、他のキーワードはこの3条件が揃っていないことが伸び悩みの根本原因。

### キーワード別の現状診断

#### 「奥沢 パーソナルジム」「自由が丘 パーソナルジム」

**SERPの構造的問題:**
- 1ページ目はMELOS、FIT PALETTE、cloud-gym 等の比較・まとめ記事が占有
- 単一ジムの公式サイトが有機検索で1位を取るのは事実上困難
- 個別ジムが戦える土俵は **ローカルパック（Googleマップ3件枠）のみ**

戦場が違うため、「公式サイトSEO」で勝とうとしている限り構造的に勝てない。

#### 「奥沢 マッサージ」「自由が丘 マッサージ」

**実態とキーワードの不一致:**
- `<title>` に「ストレッチ＆マッサージ対応」とあるが、サービスページの実態は「ペアストレッチ」と「パーソナルトレーニング」
- マッサージという言葉は本文にほぼ登場しない
- **実際にマッサージ施術を提供しているかの実態確認が必要**

**SERPの構造的問題:**
- 「奥沢 マッサージ」検索者は整体院・リラクゼーションサロン・リフレクソロジーを探している
- 検索意図がパーソナルジムと異なる
- 上位は ekiten、ホットペッパービューティーの個別店舗ページ

### 対応の選択肢：「マッサージ」キーワードの扱い

実態と乖離している現状を解消するため、二択。

#### 方針A：マッサージ系キーワードは諦める

- `<title>` から「マッサージ対応」を削除し「ストレッチ専門」に集中
- 「マッサージ」検索者は意図が違うため、無理に取りに行くと直帰率が上がる
- 「奥沢 マッサージ」より「奥沢 整体」「奥沢 体メンテナンス」のほうがまだ親和性が高い
- **メリット:** ブランドポジションが明確化、ストレッチ専門性がさらに強化される
- **デメリット:** マッサージ検索からの流入機会を失う

#### 方針B：マッサージサービスを実体として強化

- service.html に「マッサージ」セクションを追加（実際の施術内容・料金・所要時間）

- **メリット:** マッサージ検索流入を獲得
- **デメリット:** サービス整理・コンテンツ追加・GBP変更の工数が発生。実際に施術していない場合は法的・倫理的に不可
